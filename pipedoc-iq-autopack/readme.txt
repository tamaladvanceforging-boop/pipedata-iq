PipeDoc IQ Auto Pack 1.0.0
Install: Plugins > Add New > Upload Plugin > choose this zip > Activate. Requires PipeDoc IQ.
On first admin page load the 11 report templates are stored in the PipeDoc IQ database (Template Studio).
Use: PipeDoc IQ > Auto Pack. Upload PO / BOQ / spec sheet, review, Generate.
Needs the Gemini API key/consent/model set in PipeDoc IQ > Gemini AI Settings (only used to read the PO/BOQ text).
